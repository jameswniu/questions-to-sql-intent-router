# Referee cards

A referee card says how one number on the README is counted, where its data came from and how to make it again, read from the code and `evals/report.json` rather than from the README. Every number the report holds is filled in from it by `tools/recount.py`, the same way the README's are, and every other number names the test or file that produces it.

## Mismatches

- Run it says the first build took 2 minutes on a GitHub arm runner. That is the Start the stack step of the tests workflow in run 36018165796, read by hand, and no script measures it again.
